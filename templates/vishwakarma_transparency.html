Built to be Forked
Every activist should have this.

This portal is replicable by design. Each dashboard is powered by embedded JSON that mirrors a data file in a GitHub repository. Fork the repo, replace the JSON with your own RTI data, and your accountability portal is live — no database, minimal cost. Silence becomes a data point. Delay becomes a number. The system can no longer hide in paperwork.

01
File the RTI
Submit under Section 6, RTI Act 2005. Record the reference number, authority, and statutory deadline.
02
Update the Data
Add RTI metadata to the dashboard JSON. The dashboard is immediately live in "Awaiting Response" state — accountability starts at the moment of filing, not receipt.
03
Data Arrives
When the RTI response arrives, add the figures to the JSON. Charts and tables populate automatically. Partial responses are noted.
04
Pattern Emerges
Across multiple RTI cycles, systemic delays become visible as institutional behaviour — not isolated incidents but a pattern the public can see.
Data architecture: Each RTI dashboard = one embedded JSON object + one HTML template. Case Timeline Trackers and Submission Analytics require the Flask backend for live Zoho queries.
